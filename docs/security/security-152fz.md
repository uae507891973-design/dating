# Безопасность и соответствие 152-ФЗ (чек-лист открытой беты)

Документ фиксирует меры безопасности и соответствия перед публичным запуском
(Стадия 3.3). Отмечено, что реализовано в коде, а что — операционные задачи.

## Персональные данные (152-ФЗ)
- [x] Согласия на обработку ПДн фиксируются с версией и таймстампом (`consents`).
- [x] Возрастной ценз 18+ при заполнении анкеты.
- [x] Аудит-лог доступа/значимых действий (`audit_log`).
- [ ] Хранение ПДн на серверах РФ (Yandex/VK Cloud) — операционная настройка деплоя.
- [x] Шифрование PII в покое (телефон/почта) — AES-SIV, ключ из `PII_SECRET` (в prod — KMS).
- [x] Повторное согласие при смене версии документа (`/v1/legal/pending`, `/reconsent`).
- [x] Тексты документов доступны из API (`/v1/legal/documents/{type}`); финальные редакции — от юриста.

## Аутентификация и доступ
- [x] Вход по SMS-OTP с лимитами запросов и попыток.
- [x] JWT access/refresh с разделением типов токенов.
- [x] RBAC: роль модератора/админа для модерационных эндпоинтов.
- [x] WebSocket-чат: авторизация по токену + проверка членства в мэтче.

## Контент и доверие
- [x] Авто-модерация фото (NSFW) + ручная очередь модерации.
- [x] Контент-политика «без пошлости»: пороги отклонения/ревью.
- [x] Селфи-верификация + бейдж Verified.
- [x] Жалобы и блокировки пользователей.
- [x] Антифрод: поведенческие сигналы, trust-score, авто-флаги.
- [x] Антиспам в чате: блок ссылок/контактов для неверифицированных.

## Видеознакомство
- [x] Доступ к сессии только участникам мэтча.
- [x] Раскрытие только по обоюдному согласию (блюр по умолчанию включён).
- [ ] Защита от записи экрана и сквозное шифрование медиапотока — на стороне RTC-провайдера.

## Эксплуатация (операционные задачи перед бетой)
- [ ] Нагрузочное тестирование (подбор, чат, видео).
- [ ] Мониторинг/алертинг (APM, логи, метрики), дашборды.
- [ ] Бэкапы БД и план восстановления.
- [ ] Регулярный аудит прав доступа и ротация секретов.
- [ ] План реагирования на инциденты безопасности.

## Резюме
Прикладной контур безопасности (согласия, OTP/JWT, RBAC, модерация, верификация,
антифрод, аудит, антиспам, ограничения видео) реализован и покрыт тестами.
Оставшиеся пункты — инфраструктурные/юридические настройки уровня окружения,
выполняются при развёртывании в РФ-облаке перед открытой бетой.
