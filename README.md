## Код

- [`backend/`](backend/) — API-сервис (FastAPI). Запуск: `docker compose up --build`, далее http://localhost:8000/docs
- Стадия 0 (фундамент) реализована: каркас приложения, слой БД + миграции, healthcheck, аналитика, Docker/Compose, CI.
- Стадия 1.1 реализована: регистрация по SMS-OTP, JWT (access/refresh), фиксация согласий (152-ФЗ).
- Стадия 1.2 реализована: тест совместимости, психопрофиль, намерение, функция совместимости.
- Стадия 1.3 реализована: анкета (18+), загрузка фото, авто-модерация NSFW + ручная очередь.
- Стадия 1.4 реализована: селфи-верификация + бейдж, жалобы/блокировки, аудит-лог. **MVP-ядро (Стадия 1) завершено.**
- Стадия 2.1 реализована: движок подбора (фильтры + ранжирование совместимостью), лайки/пропуски, мэтчи.
- Стадия 2.2 реализована: объяснимый мэтчинг («Почему вы подходите») + scrutability (важность факторов).
- Стадия 2.3 реализована: чат (сообщения, история, айсбрейкеры, модерация, WebSocket). **Стадия 2 завершена.**
- Стадия 3.1 реализована: антифрод-движок (поведенческие сигналы, trust-score, авто-флаги).

## Кратко

- **Рынок:** ~8–10 млрд ₽, ~8 млн MAU; лидеры Mamba (39%) и VK Знакомства (29%).
- **Тренд 2025:** осознанный поиск долгосрочных отношений, AI-совместимость, борьба с ботами.
- **Наше право на существование:** объяснимый мэтчинг по ценностям, verified-by-default, slow dating, безопасность как фича.
