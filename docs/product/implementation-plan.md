# План реализации продукта

Кодовое имя: **epic-davinci**. Ниша: серьёзные онлайн-знакомства в России, без откровенного контента, с фокусом на доверие и совместимость.

Документ объединяет выводы исследования рынка ([dating-market-ru.md](../research/dating-market-ru.md)),
анализа конкурентов ([competitor-analysis.md](./competitor-analysis.md)), дорожной карты ([roadmap.md](./roadmap.md))
и CJM ([cjm.md](./cjm.md)) в конкретный план действий, а также содержит оригинальные идеи (раздел 6).

---

## 1. Видение продукта

> «Серьёзные знакомства, основанные на доверии и совместимости».

Мы строим не «ещё один свайпер», а **платформу осознанных знакомств**, где AI подбирает по ценностям и психотипу,
а каждая анкета верифицирована. Главные ценности бренда: **доверие, безопасность, отсутствие пошлости, реальный результат**.

**Целевая аудитория:** мужчины и женщины 28–45 лет, ищущие долгосрочные отношения и семью; ценящие традиционные ценности и уважительное общение.

## 2. Целевая архитектура (предложение)

| Слой | Технология (предложение) | Обоснование |
|---|---|---|
| Мобильные клиенты | React Native (iOS/Android) | единая кодовая база, быстрый MVP, RuStore-совместимость |
| Web | Next.js (SSR) | SEO для органики, лендинги |
| Backend API | Python (FastAPI) или Node (NestJS) | быстрый старт, экосистема ML на Python |
| Realtime (чат/видео) | WebSocket + WebRTC (или Voximplant/RTC РФ) | звонки без обмена контактами |
| БД | PostgreSQL + Redis (кэш/сессии) | надёжность, гео-запросы (PostGIS) |
| Поиск/мэтчинг | Elasticsearch/OpenSearch + сервис рекомендаций | гео + фильтры + скоринг совместимости |
| ML/AI | Python-сервис (эмбеддинги анкет, скоринг, модерация) | подбор и антифрод |
| Модерация контента | AI (NSFW-классификатор) + ручная очередь | контент-политика без пошлости |
| Инфраструктура | РФ-хостинг (Yandex Cloud/VK Cloud), Docker, CI/CD | требования 152-ФЗ о хранении ПДн в РФ |
| Аналитика | self-hosted (например, ClickHouse + метрики событий) | продуктовая аналитика без внешних утечек |

> Стек — рекомендация, финализируется в Фазе 0 по результатам оценки команды.

**Контур безопасности и комплаенс:**
- Хранение персональных данных на территории РФ (152-ФЗ).
- Шифрование PII в покое и в транзите, минимизация данных.
- Согласия на обработку ПДн, политика конфиденциальности, возрастной ценз 18+.
- Журналирование доступа, регулярные бэкапы.

## 3. Декомпозиция по фазам и бэклог (Epics → User Stories)

### Фаза 1 — MVP (мес. 3–5)

**Epic A. Регистрация и онбординг**
- Как новый пользователь, я хочу зарегистрироваться по телефону/email, чтобы начать.
- Как новый пользователь, я хочу пройти тест ценностей/психотипа (16–20 вопросов), чтобы получать релевантные пары.
- Как пользователь, я хочу заполнить анкету (фото, о себе, цели), чтобы меня нашли.

**Epic B. Доверие и безопасность**
- Как пользователь, я хочу пройти селфи-верификацию и получить бейдж Verified.
- Как пользователь, я хочу пожаловаться/заблокировать собеседника.
- Как модератор, я хочу очередь жалоб и авто-детект NSFW-контента.

**Epic C. Мэтчинг**
- Как пользователь, я хочу ежедневную подборку совместимых анкет с % совместимости.
- Как пользователь, я хочу видеть «почему мы подходим» (объяснимость).
- Как пользователь, я хочу лайкать/пропускать и получать мэтч при взаимности.

**Epic D. Коммуникация**
- Как пользователь, я хочу чат после мэтча с подсказками-айсбрейкерами.

**Критерий выхода MVP:** D1-retention ≥ 25%, доля верифицированных ≥ 60%, ≥ 1 качественный мэтч на активного пользователя в неделю.

### Фаза 2 — Engagement & Trust (мес. 6–8)
- Видеознакомство (WebRTC), уровни доверия профиля, гео «рядом», антифрод-движок, push-уведомления.

### Фаза 3 — Монетизация (мес. 9–11)
- Подписка (платёжный провайдер РФ: ЮKassa/CloudPayments), пакеты бустов, paywall-эксперименты.

### Фаза 4 — Рост (мес. 12+)
- Реферальная программа, контент-маркетинг, регионы, ML-оптимизация мэтчинга.

## 4. Метрики и KPI по фазам

| Фаза | Главные метрики | Целевые ориентиры |
|---|---|---|
| MVP | D1/D7 retention, % верификации, completion онбординга | D7 ≥ 15%, верификация ≥ 60% |
| Engagement | mutual matches/user, % чатов с ответом, видеозвонки | ответ на первое сообщение ≥ 40% |
| Монетизация | conversion to paid, ARPPU, churn | conversion 3–5%, churn < 10%/мес |
| Рост | CAC, LTV, K-фактор (рефералы), MAU | LTV/CAC > 3 |

Сквозная метрика качества: **доля пользователей, дошедших до оффлайн-свидания** (опрос/самоотчёт).

## 5. Риски и митигации

| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| Боты/скам подрывают доверие | Высокая | Критич. | Verified-by-default, антифрод-ML, ручная модерация |
| «Холодный старт» (мало анкет) | Высокая | Высокое | Запуск по городам, посев аудитории, реферальная программа |
| Гендерный перекос | Средняя | Высокое | Привлечение женской аудитории, women-first фичи, бесплатные функции для дефицитного сегмента |
| Регуляторика (152-ФЗ, контент) | Средняя | Высокое | РФ-хостинг, юридическая проверка, строгая контент-политика |
| Зависимость от платежей/сторов | Средняя | Среднее | RuStore + прямые платежи РФ |
| Дисбаланс монетизации vs опыт | Средняя | Среднее | Аккуратный paywall, ценность бесплатного ядра |

## 6. Собственные идеи для улучшения сервиса (сверх исследования)

Идеи, которых нет или которые слабо реализованы у конкурентов, сгруппированы по приоритету.

### 🔥 Высокий приоритет (дифференциаторы MVP/Фаза 2)
1. **Объяснимый мэтчинг («Почему вы подходите»)** — показывать 2–3 конкретные причины совпадения (общие ценности, цели, интересы). Повышает доверие к алгоритму, чего нет у конкурентов.
2. **Slow dating режим** — ограниченное число качественных мэтчей в день вместо бесконечной ленты. Бьёт в тренд осознанности и выгорания от свайпов.
3. **Verified-by-default + «Шкала доверия»** — публичный уровень доверия профиля (верификация телефона, селфи, соцсети, давность аккаунта, отзывы после свиданий). Доверие как видимый продукт.
4. **Видеознакомство «вслепую»** — короткий видеозвонок с размытием до момента взаимного согласия открыть видео. Безопасный первый контакт без обмена контактами.
5. **Safety-кит свидания** — кнопка «поделиться деталями свидания и геолокацией с доверенным контактом», SOS-кнопка, чек-лист безопасности. Превращает безопасность в фичу бренда.

### 🟡 Средний приоритет (удержание/рост)
6. **AI-ассистент общения** — деликатные подсказки айсбрейкеров и тем на основе общих интересов (не пишет за пользователя, а помогает начать). Снижает «тишину в чате».
7. **Анти-гост механика** — мягкие напоминания и метрика отзывчивости профиля; «вежливый отказ» в один тап вместо игнора.
8. **Совместные мини-активности** — встроенные игры/вопросы дня для пары в чате, чтобы прогреть общение до встречи.
9. **«Намерения» вместо «статуса»** — пользователь явно указывает цель (брак/долгие отношения/дружба), и алгоритм матчит только совпадающие намерения. Убирает рассинхрон ожиданий.
10. **Женский комфорт-режим** — первое сообщение по приглашению, фильтр по уровню доверия, скрытие онлайн-статуса. Решает гендерный перекос и проблему навязчивости.

### 🟢 Долгосрочные / визионерские
11. **Постматч-обратная связь и обучение модели** — после свидания приватная оценка («совпало ли описание с реальностью»), которая улучшает скоринг и борется с фейками.
12. **Оффлайн-комьюнити** — кураторские оффлайн-события и тематические встречи (партнёрства), мост из онлайна в реальную жизнь — то, чего нет у чисто-онлайн конкурентов.
13. **Партнёрство с психологами** — контент и опциональные консультации по отношениям; усиливает позиционирование «осознанных знакомств».
14. **Антифрод-граф** — выявление сетей мошенников по поведенческим и сетевым признакам (общие устройства, шаблоны сообщений, скорость действий).
15. **Этичная монетизация** — отказ от «pay-to-see-likes» как единственного крючка; вместо этого премиум за качество (расширенная совместимость, приоритет у верифицированных). Бренд «честного дейтинга».
