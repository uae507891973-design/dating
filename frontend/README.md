# epic-davinci — визуальный интерфейс (прототип)

Самодостаточный кликабельный прототип реализованного функционала (Стадии 0–3).
Без сборки и зависимостей — чистый HTML/CSS/JS. Данные моковые, но повторяют
формат реального API backend.

## Запуск

Откройте `index.html` в браузере (двойной клик) — или поднимите статический сервер:

```bash
cd frontend
python3 -m http.server 5173
# затем откройте http://localhost:5173
```

## Что показано
- **Тест совместимости** — вопросы по категориям, шкала ответов, важность фактора.
- **Подбор** — карточка с % совместимости, бейджем Verified и блоком
  «Почему вы подходите» (объяснимый мэтчинг) + настройка важности категорий (scrutability).
- **Чат** — список мэтчей, переписка, айсбрейкеры, отправка сообщений.
- **Видеознакомство «вслепую»** — размытие, таймер, согласие на раскрытие, завершение.
- **Профиль** — намерение, прогресс теста, верификация, доверие, безопасность/152-ФЗ.

> Это визуальная демонстрация UX поверх уже реализованного backend
> (`../backend`). Боевой клиент по плану — React Native + Next.js.
